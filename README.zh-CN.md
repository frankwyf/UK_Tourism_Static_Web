# 英国旅游现代化静态网站

本项目是英国旅游主题静态网站的现代化重构，旨在展示原生Web开发能力，适合开源展示与面试作品集。

## 目录结构
- src/      —— 主要页面源码（HTML5+CSS3+ES6）
- public/   —— 入口文件、favicon等公共资源
- assets/   —— 图片、音视频等静态资源
- scripts/  —— 构建、自动化脚本
- docs/     —— 设计文档、开发说明

## 技术栈
- HTML5 语义化标签
- CSS3（Flexbox、Grid、变量、响应式、深色模式）
- 原生JavaScript（ES6+，模块化，组件化）
- 零依赖/轻依赖（可选Bootstrap、PostCSS等）
- 自动化构建（可选Webpack/Vite）

## 主要特性
- 响应式设计，适配PC与移动端
- 现代交互体验，动画与过渡
- 代码结构清晰，注释完善
- 可访问性（a11y）、SEO优化

## 快速开始
1. 克隆仓库
2. 直接用浏览器打开 public/index.html 或用本地服务器预览
3. 参考 docs/ 了解设计与开发细节
