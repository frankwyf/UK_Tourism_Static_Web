# 英国旅游静态网站（合并最终版）

[English](README.md) | [日本語](README.ja.md)

本仓库是对原始 CWK1 和 CWK2 作业网站的完整迁移与合并，产出一个可开源发布的最终版本。

## 合并策略
- 以 CWK2 final work 作为基础（内容更完整、交互更多）
- 对 CWK1 与 CWK2 做重复比对后合并为单一最终版
- 保持原始页面结构、视觉风格与交互行为

## 脱敏处理
已对可发布站点文件完成隐私脱敏：
- 个人姓名
- 学号信息
- 个人邮箱

除隐私字段替换外，页面内容与效果保持与原始最终版一致。

## 目录结构
- site/: 可直接运行的网站文件（保留原始相对路径结构）
- docs/: 项目与开源文档

## 本地运行
1. 浏览器打开 site/index.html
2. 如遇本地文件策略限制，可使用静态服务器运行
