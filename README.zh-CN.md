# 英国旅游静态网站

[English](README.md) | [日本語](README.ja.md)

本仓库是一个面向开源发布的英国旅游静态网站项目，用于展示完整的静态 Web 工程实现能力。

## 项目定位
- 可复用、可发布的开源静态站点代码库
- 覆盖英格兰、威尔士、苏格兰、北爱尔兰四大主题页面
- 强调 HTML 语义化、CSS 结构化与 JavaScript 交互实现

## 主要功能
- 多页面导航与锚点跳转
- 图片、音频、视频等多媒体内容整合
- 地图、当前时间、当前位置等前端交互模块
- 基于 Web Storage 的轻量本地状态存储
- 结合自定义样式与 Bootstrap 的响应式布局

## 脱敏处理
已对可发布站点文件完成隐私脱敏：
- 个人姓名
- 个人标识信息
- 个人邮箱

除隐私字段替换外，页面内容与效果保持一致。

## 目录结构
- site/: 可直接运行的网站文件（保留原始相对路径结构）
- docs/: 项目与开源文档

## 本地运行
1. 浏览器打开 site/index.html
2. 如遇本地文件策略限制，可使用静态服务器运行

## 工程能力亮点
- 统一的相对路径资源组织，便于离线运行与部署迁移
- 结构、样式、行为分层清晰，维护成本低
- 在脚本受限场景下依旧保持页面可读性
- 跨页面复用导航、页脚与通用脚本逻辑
