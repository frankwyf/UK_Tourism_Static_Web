# UK観光静的サイト（統合最終版）

[English](README.md) | [中文](README.zh-CN.md)

本リポジトリは、元の CWK1/CWK2 サイトを完全移行し、1つの最終オープンソース版へ統合したものです。

## 統合方針
- ベース: CWK2 final work（機能と構成がより充実）
- CWK1/CWK2 の重複を比較し、最終版として一本化
- 元サイトの構造・見た目・挙動を維持

## 匿名化
公開用サイトファイルから以下を除去しました:
- 個人名
- 学籍番号
- 個人メールアドレス

プライバシー関連の置換以外は、元の最終版と同等の表示・体験を維持しています。

## 構成
- site/: 実行可能な最終サイト（相対パス構造を維持）
- docs/: プロジェクト・OSSドキュメント

## ローカル実行
1. site/index.html をブラウザで開く
2. 制限がある場合は静的サーバーで実行
