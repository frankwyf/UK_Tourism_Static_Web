# 英国観光モダン静的ウェブサイト

本プロジェクトは、英国観光をテーマにした静的ウェブサイトのモダンリファクタリング版です。ネイティブWeb開発スキルをアピールするため、オープンソースや就職活動のポートフォリオに最適です。

## ディレクトリ構成
- src/      —— メインページのソースコード（HTML5+CSS3+ES6）
- public/   —— エントリーファイル、faviconなどの共通リソース
- assets/   —— 画像・音声・動画などの静的リソース
- scripts/  —— ビルド・自動化スクリプト
- docs/     —— 設計ドキュメント・開発ガイド

## 技術スタック
- HTML5 セマンティックタグ
- CSS3（Flexbox、Grid、変数、レスポンシブ、ダークモード）
- ネイティブJavaScript（ES6+、モジュール化、コンポーネント化）
- ノンフレームワーク/軽量依存（Bootstrap、PostCSS等も可）
- 自動化ビルド（Webpack/Vite等も可）

## 主な特徴
- レスポンシブデザイン、PC・モバイル両対応
- モダンなインタラクション、アニメーション
- コード構造が明確でコメント充実
- アクセシビリティ（a11y）、SEO最適化

## クイックスタート
1. リポジトリをクローン
2. public/index.html を直接ブラウザで開くか、ローカルサーバーでプレビュー
3. docs/ を参照し設計・開発詳細を確認
