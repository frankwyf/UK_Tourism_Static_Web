# UK観光静的サイト

[English](README.md) | [中文](README.zh-CN.md)

本リポジトリは、英国観光情報を題材にしたオープンソース公開向けの静的 Web サイトです。静的 Web 開発の実装力を示すポートフォリオとして構成しています。

## プロジェクト方針
- 公開・再利用しやすい静的サイト構成
- England / Wales / Scotland / Northern Ireland の複数ページ情報設計
- HTML / CSS / JavaScript の責務分離を重視した実装

## 主な機能
- マルチページナビゲーションとアンカー遷移
- 画像・音声・動画を組み合わせたメディア体験
- 地図表示、現在時刻、現在地などのフロントエンド機能
- Web Storage を使った軽量なクライアント側状態保持
- Bootstrap とカスタム CSS を組み合わせたレスポンシブ対応

## 匿名化
公開用サイトファイルから以下を除去しました:
- 個人名
- 個人識別情報
- 個人メールアドレス

プライバシー関連の置換以外は、表示・体験を維持しています。

## 構成
- site/: 実行可能な最終サイト（相対パス構造を維持）
- docs/: プロジェクト・OSSドキュメント

## ローカル実行
1. site/index.html をブラウザで開く
2. 制限がある場合は静的サーバーで実行

## 実装ハイライト
- 相対パス中心の堅牢なアセット参照設計
- 構造・見た目・挙動の分離による保守性向上
- スクリプト制限時も読める段階的拡張の設計
- ナビゲーションや共通フッターのページ横断再利用
