# 常见问题（FAQ）

**Q: 这个项目可以直接商用吗？**
A: 遵循 MIT License，可自由使用、修改、分发，但请保留原作者信息。

**Q: 如何本地预览？**
A: 直接用浏览器打开 public/index.html，或用 VSCode Live Server 插件、本地 http-server 工具等。

**Q: 可以用React/Vue重写吗？**
A: 本项目主旨是展现原生Web开发能力，建议以原生为主。如需框架重写可另建分支。

**Q: 资源太多，如何管理？**
A: 建议统一放在 assets/，并按地区/类型分类。

**Q: 如何参与贡献？**
A: 详见 CONTRIBUTING.md，欢迎PR和建议。
