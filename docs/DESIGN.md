# 设计说明（DESIGN）

## 设计目标
- 充分展现原生Web开发能力，代码结构清晰、注释完善
- 响应式布局，适配多终端
- 现代交互体验，动画与过渡自然
- 兼顾可访问性（a11y）与SEO

## 页面结构
- 首页（index.html）：导航+各地区简介+项目介绍
- 各地区页面（可扩展）：England、Scotland、Wales、Northern Ireland
- 关于页/作者页（可扩展）

## 技术选型
- HTML5语义化标签
- CSS3（Flexbox、Grid、变量、媒体查询、深色模式）
- 原生JavaScript（ES6+，模块化，组件化）
- 零依赖/轻依赖，突出底层能力

## 交互与体验
- 平滑滚动导航
- 响应式菜单
- 可扩展的深色模式
- 轻量动画与过渡

## 资源与扩展
- 所有图片、音视频资源统一放置于 assets/
- 可扩展更多页面与功能（如旅游计划、景点、攻略等）

## 代码规范
- 统一缩进、命名风格
- 充分注释，便于他人理解
- 适当拆分模块，提升可维护性
